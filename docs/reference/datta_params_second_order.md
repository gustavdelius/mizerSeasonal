# Second-order parameters used by Datta & Blanchard (2016)

A variant of
[datta_params](https://gustavdelius.github.io/mizerSeasonal/reference/datta_params.md)
created with `second_order_w = TRUE`. It uses the second-order van Leer
flux scheme and bin-averaged quantities, and its initial state is set to
the steady state of the second-order model.

## Usage

``` r
datta_params_second_order
```

## Format

A MizerParams object

## Source

Datta, S. & Blanchard, J. L. "The effects of seasonal processes on size
spectrum dynamics". Canadian Journal of Fisheries and Aquatic Sciences
(2016). <https://cdnsciencepub.com/doi/full/10.1139/cjfas-2015-0468>

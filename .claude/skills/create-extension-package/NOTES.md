# Project notes

- `mizerSeasonal` is a dispatching extension: `projectEncounter.mizerSeasonal`
  adds to `NextMethod()`, while `projectRDI.mizerSeasonal` intentionally
  replaces the base RDI calculation.
- `setSeasonalReproduction()` installs the `gonads` component, selects the RDD
  rate function, records the extension and its version, and then coerces the
  object to the dynamic marker class.
